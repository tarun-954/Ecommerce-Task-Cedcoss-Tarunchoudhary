🛒 Ecommerce Task – Cedcoss

A modern and responsive Ecommerce Frontend Application built as part of the Cedcoss technical assignment.
This project focuses on UI/UX design, component reusability, and interactive product selection features using a scalable frontend architecture.

📌 Overview

This project simulates a basic ecommerce interface with emphasis on:

Clean and responsive UI design
Interactive product/order cards
Hover and selection-based interactions
Component-driven architecture
Fast development experience using Vite

✨ Features
🛍️ Product listing interface
🧩 Reusable UI components
🎯 Hover-to-select card interaction
📦 Order/product card layout
📱 Fully responsive design (mobile + desktop)
⚡ Optimized with Vite for fast builds
🎨 Modern UI styling

🧰 Tech Stack
Frontend: React.js
Language: TypeScript / JavaScript (based on your setup)
Bundler: Vite
Styling: Tailwind CSS / CSS Modules (update if needed)
State Management: React Hooks

📁 Project Structure
src/
│
├── components/        # Reusable UI components
├── pages/             # Application pages/views
├── assets/            # Static assets (images, icons)
├── hooks/             # Custom React hooks (if any)
├── utils/             # Helper functions
├── App.tsx            # Root component
└── main.tsx           # Application entry point

⚙️ Getting Started

Follow these steps to run the project locally:

1️⃣ Clone the repository
git clone https://github.com/tarun-954/Ecommerce-Task-Cedcoss-Tarunchoudhary.git
2️⃣ Navigate to project directory
cd Ecommerce-Task-Cedcoss-Tarunchoudhary
3️⃣ Install dependencies
npm install
4️⃣ Start development server
npm run dev
🏗️ Build for Production
npm run build
